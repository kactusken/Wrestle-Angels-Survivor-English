# Screenshots

and scaled to 4:3.

Logos are left as they are.

## The office

![The office: main menu, Staff submenu and help line](screenshots/office.png)

Management mode's main menu, its submenus and the help line, with the AP, year and month counter
re-lettered.

## Events

![A tryout event with Honeybee Fujishima](screenshots/tryout-event.png)

![Signing Freya Kagami](screenshots/signing.png)

All 8,348 event messages are translated: tryouts, scouting and signing talks, vacations, title
changes, retirements, with the speaker's name in the name box.

## Wrestler info

![A wrestler's info page during transfer talks](screenshots/wrestler-info.png)

The info pages print each value into a fixed slot made for the Japanese; their formats and
cut-outs were reworked in the game's code to fit English.
