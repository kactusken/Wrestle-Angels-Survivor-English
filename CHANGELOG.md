# Changelog

## v0.1
First release. Tested in PCSX2 across exhibition (Special Match, Tournament, League) and
management mode.

- Everything translated: all 8,348 event messages, menus and help, wrestler names and finishers,
  nicknames and titles, venue names (384), the ring announcer, pre-match quotes, and 911
  pictures with Japanese lettering (menus, buttons, banners, match screens, name strips,
  portraits). Face pictures keep their Japanese name and add the English along the bottom.
  The staff credits are left in Japanese.
- Promotion names follow each promotion's own logo.
- Screens rearranged where English didn't fit: the wrestler info pages, rankings, save/load
  slots, map titles, menu highlights, list columns.
- Three patches: English; English with the gallery and the 52 alternate wrestlers unlocked;
  the Japanese game with the same unlocks. Plus PCSX2 cheats for all of them and the original
  game (money, wrestler stats, every random event, the full gallery, hidden scenes).
